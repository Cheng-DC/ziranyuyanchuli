### 定义LSTM模型

`python`

	class SimpleLSTM(nn.Module):
    	def __init__(self, input_size, hidden_size, output_size):
        	super().__init__()
        	self.lstm = nn.LSTM(input_size, hidden_size, batch_first=True)
        	self.fc = nn.Linear(hidden_size, output_size)
    
    	def forward(self, x):
        	out, _ = self.lstm(x)          # LSTM处理序列
        	out = self.fc(out[:, -1, :])   # 取最后一个时间步的输出
        	return out
**结构特点：**

单层LSTM（32个隐藏单元）

全连接输出层（将LSTM输出映射为预测值）

batch_first=True：输入格式为(batch, seq, feature)

### 模型训练
损失函数：均方误差（MSELoss）

优化器：随机梯度下降（SGD），学习率0.01

训练过程：500个epoch，每100个epoch打印损失

训练效果：由于是简单线性序列，损失应快速收敛

### 模型预测
测试输入：[[70, 80, 90]]（形状调整为(1, 3, 1)）

预测输出：模型预测的下一个值（期望值应为100）

### 输出结果
训练过程中每100个epoch的损失值（应逐渐减小）

最终的预测值（应接近100）

### 三种分词模式
**a. 全模式分词**

特点：尽可能多地切分词语，输出所有可能的组合

优点：召回率高（能找到所有可能的词语）

缺点：准确率低（会产生冗余的词语组合）

适用场景：需要找出所有可能词语组合的场合

**b. 精确模式分词**

特点：最常用的模式，将句子精确地切开，无冗余

优点：准确率高

缺点：可能会遗漏一些不常见的词语组合

适用场景：大多数文本分析任务

**c. 搜索引擎模式分词**

特点：在精确模式基础上，对长词再次切分

优点：适合搜索引擎建立索引

缺点：会产生比精确模式更多的词语

适用场景：搜索引擎索引构建、全文检索等

三种分词模式的区别示例
假设文本："我爱自然语言处理"

全模式：我/爱/自然/自然语言/语言/处理

精确模式：我/爱/自然语言/处理

搜索引擎模式：我/爱/自然/语言/自然语言/处理
